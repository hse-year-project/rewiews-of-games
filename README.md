Steam показывает только итоговую оценку игры и простой график отзывов. Наш проект идёт дальше:

- разбивает отзывы на **типы** (жалобы на оптимизацию, перевод, читеров, цену, похвала сюжету и т. д.);
- показывает, **как менялось настроение** и какие события (патчи, скидки, релизы конкурентов) за этим стоят;
- **прогнозирует** настроение и онлайн на ближайшие недели;
- сравнивает реакцию **русско-, англо- и китайскоязычной** аудитории.

## Как это работает

```
 Steam APIs ──► Парсеры ──► PostgreSQL ──┬──► Кластеризация отзывов ──┐
                                         ├──► Временные ряды ─────────┼──► FastAPI ──► Дашборд
                                         └──► Эмбеддинги игр ─────────┘
```

1. **Сбор.** Парсеры забирают отзывы, новости/патчи, онлайн.
2. **Типизация отзывов.** Тексты преобразуются в векторы мультиязычной моделью и группируются в кластеры, то есть типы отзывов.
3. **Временные ряды.** Для каждой игры строятся дневные ряды: число отзывов, доля 👍, доля каждого типа отзывов, онлайн.
4. **Прогноз.** Модели предсказывают будущие значения рядов с учётом событий и похожих игр.
5. **Сервис.** Всё это доступно через API и дашборд.

## Данные

### Источники

| Источник | Что берём |
|---|---|
| `store.steampowered.com/appreviews/{appid}?json=1` | Отзывы: текст, 👍/👎, дата, язык, часы в игре, полезность, тип покупки |
| `ISteamNews/GetNewsForApp` | Новости и патчноуты |
| `store.steampowered.com/api/appdetails` | Жанры, цена, дата релиза, F2P/платная |
| `SteamCharts` | История онлайна |

### Языки

Анализ ограничен тремя языками (параметр `language` в Steam Reviews API):

| Язык | Код Steam | Почему |
|---|---|---|
| 🇬🇧 Английский | `english` | Самый большой объём отзывов, «глобальная» аудитория |
| 🇷🇺 Русский | `russian` | Крупный сегмент, своя специфика (региональные цены, доступность оплаты) |
| 🇨🇳 Китайский *(под вопросом)* | `schinese/tchinese` | Один из крупнейших сегментов Steam; хорошо отражает проблемы локализации, серверов и региональных ограничений |

### Выборка игр

Стартуем с **30–100 игр**, покрывающих разные сценарии:

- онлайн-игры с частыми патчами (Counter-Strike 2, Dota 2);
- игры с известными волнами негатива (Helldivers 2, Cyberpunk 2077, Overwatch 2, Slay the Spire 2);
- сюжетные одиночные игры (Baldur's Gate 3);
- инди-игры с небольшим числом отзывов;
- группы конкурентов внутри одного жанра.

## Типы отзывов (кластеризация)

Заранее неизвестно, **какие типы отзывов** вообще встречаются. Поэтому вместо ручной разметки мы находим их автоматически.

**Зачем это нужно:**
- Одна общая цифра «78% положительных» скрывает, *о чём* жалуются. Кластеры показывают, что, например, после патча выросла доля жалоб на баги, а не на цену.
- Разметка настроения не нужна. Метка 👍/👎 у каждого отзыва уже есть в Steam, а кластеры добавляют к ней тему.
- Доли кластеров во времени становятся дополнительными рядами и признаками для прогноза.

**Пайплайн:**

```
текст ──► очистка ──► мультиязычные эмбеддинги ──► UMAP ──► HDBSCAN ──► именование кластеров
                      (multilingual-e5 / LaBSE)            (BERTopic)   (c-TF-IDF + LLM)
```

- **Мультиязычная модель эмбеддингов** нужна, чтобы отзыв «оптимизация ужасная» и «terrible optimization» попали в один кластер, а не в разные кластеры по языкам.
- **HDBSCAN** сам определяет число кластеров и выделяет нетипичные отзывы в шум.
- **Названия кластерам** даются по характерным словам и с помощью LLM, затем проверяются вручную.

**Что получаем в итоге:**

| Метрика | Пример |
|---|---|
| Доля типа отзывов за период | «Жалобы на перевод» - 12% китайских отзывов за неделю |
| Тип × 👍/👎 | Какие темы встречаются в основном в негативных отзывах |
| Тип × язык | Проблема перевода видна только в одном языке |
| Тип во времени | Всплеск «жалоб на серверы» в день патча |

> Для проверки качества кластеров вручную просматривается небольшая выборка.

## Исследование данных (EDA)

1. **Сбор.** Выгружаем отзывы (RU / EN / ZH), патчноуты и метаданные игр. Смотрим объём данных по играм, языкам и времени.
2. **Очистка.** Удаляем дубликаты, пустые и мусорные тексты (мемы, ASCII-арты), отзывы с неверно указанным языком и подозрительные аккаунты. Решаем, к какой дате относить отредактированные отзывы. Фиксируем, сколько данных отброшено.
3. **Срез отзывов.** Сравниваем распределение 👍/👎 по играм, жанрам и языкам. Смотрим, как оценка связана с длиной текста, часами в игре и полезностью отзыва.
4. **Типы отзывов.** Строим мультиязычные эмбеддинги и кластеризуем их (UMAP + HDBSCAN). Проверяем, что кластеры собираются по смыслу, а не по языку. Даём кластерам названия и вручную проверяем выборку. Смотрим срезы: тип × 👍/👎 × язык.
5. **Временные ряды.** Строим дневные ряды: число отзывов, доля 👍, доли типов отзывов, онлайн. Изучаем тренд, сезонность (дни недели, распродажи), стационарность и автокорреляцию. Ищем аномалии вроде review bombing.
6. **События и онлайн.** Оцениваем эффект патчей в окне ±7/14 дней: какие типы отзывов растут после каких патчей. Проверяем, что меняется раньше: настроение или онлайн.
7. **Аудитория и связи игр.** Сравниваем RU / EN / ZH. Оцениваем платёжеспособность по косвенным признакам (размер библиотеки, региональные цены). Строим граф пересечения аудитории игр и оцениваем эффект релизов конкурентов.
8. **Итоги.** Готовим отчёт с ключевыми графиками, список признаков и гипотезы для моделей. Примеры гипотез:
   - доля технических жалоб предсказывает падение онлайна лучше, чем общая доля 👎;
   - онлайн реагирует на ухудшение настроения с задержкой;
   - проблемы локализации видны в одном языке раньше, чем в общей оценке;
   - негатив после крупного патча возвращается к норме за 2–4 недели.
## Модели

### Отзывы
| Задача | Подход |
|---|---|
| Типы отзывов | Мультиязычные эмбеддинги + UMAP + HDBSCAN (BERTopic) |
| Именование кластеров | c-TF-IDF + LLM |
| Тональность текста | Готовые мультиязычные sentiment-модели без дообучения; 👍/👎 как слабая метка для проверки |

### Прогноз временных рядов
| Группа | Модели |
|---|---|
| Baseline | Последнее значение, сезонное наивное, скользящее среднее |
| Классические | SARIMA(X), ETS, Prophet |
| ML на признаках | CatBoost / LightGBM: лаги, календарь, патчи, скидки, доли кластеров |
| Нейросети | LSTM, N-BEATS, N-HiTS, Temporal Fusion Transformer |
| Foundation / LLM | Chronos, TimesFM, Lag-Llama, Moirai |

Метрики: MAE, RMSE, sMAPE, MASE. Валидация: backtesting со скользящим окном.

### Эмбеддинги игр
- node2vec / GNN по графу пересечения аудитории
- Текстовые эмбеддинги описаний и тегов
- Использование как признаков в прогнозе и для поиска похожих игр

## Roadmap
 
- **Старт**: тема, план, репозиторий
- **Данные и EDA**: парсеры, датасет, кластеры отзывов
- **Baseline-модели**: первые прогнозы, сравнение моделей
- **Сервис**: FastAPI + Streamlit + Docker
- **Улучшение моделей**: события, кластеры и эмбеддинги игр как признаки
- **Нейросети**: нейросетевые и foundation-модели временных рядов
